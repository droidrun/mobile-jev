# agents/cli/base/

Formats OAuth login output for agent CLI commands.

Keep agent-specific terminal helpers here; general terminal rendering lives in `cli/base/`.

## Files

| File | Purpose |
| --- | --- |
| `__init__.py` | Package marker; no public names defined. |
| `oauth_output.py` | `console`, `_print_oauth_login_success`, `_validate_oauth_timeout` — OAuth terminal output and timeout checks. |


See [agent commands](../README.md).
